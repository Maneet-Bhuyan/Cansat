1. SYSTEM ARCHITECTURE & ENGINEERING OVERVIEW
--------------------------------------------------------------------------------
The Cognitive CanSat Platform is a hybrid real-time telemetry processing, flight 
dynamics visualization, and Machine Learning (ML) inference suite built for 
atmospheric sounding pico-satellites (CanSats).

The architecture is composed of two synchronized layers:
1. High-Performance WebGL/Canvas Ground Station Frontend (`index.html`):
   - Ingests raw serial telemetry directly from USB UART bridges (LoRa SX1276 / 
     SX1262 transceivers connected to ESP32/STM32) via the Web Serial API at 115200 baud.
   - Renders 60 FPS 3D kinematic digital twins in Three.js, 7 concurrent high-frequency 
     Canvas 2D line charts in Chart.js, and multi-layer WGS-84 GIS mapping in Leaflet.js.
   - Provides instant client-side fallback processing if the Python server is offline.

2. Real-Time Python Machine Learning Backend (`backend/app.py`):
   - Powered by FastAPI, Uvicorn, scikit-learn, PyOD, and joblib.
   - Executes multi-model machine learning inference per telemetry packet in under 2ms.
   - Serves REST endpoints (`POST /api/predict`) and full-duplex WebSocket streams (`WS /ws/telemetry`).

2. REAL-WORLD APPLICATIONS & DOMAIN USE CASES
--------------------------------------------------------------------------------

A. Aerospace & Student CanSat Competitions (ESA, NASA/AIAA, CANSAT):
   - End-to-end mission control, automated flight phase sequencing, apogee verification, 
     and RFC 4180 CSV competition data logging.

B. Atmospheric Thermodynamics & Meteorological Sounding:
   - High-resolution altitude profiling of atmospheric lapse rates, temperature inversions, 
     Magnus-Tetens dew point, and Ideal Gas Law air density distributions.

C. Sounding Rockets & High-Altitude Ballooning (HAB):
   - Real-time kinematic tracking of high-speed ascent, apogee ejection shock, 
     chaotic tumble dynamics, and parachute descent stability.

D. Rapid Field Recovery & Search-and-Rescue (SAR):
   - Live GPS tracking with dual color-coded ascent/descent breadcrumbs, automated 
     touchdown coordinate locking, and 1-click Google Maps navigation routing.

E. Pre-Flight Mission Simulation & Anomaly Stress Testing:
   - 10 full-mission test profiles (bursts, wind shear, delayed chutes, tumble, voltage sags) 
     for software-in-the-loop (SIL) testing and flight readiness drills.

4. SCIENTIFIC COMPUTING & CONTROL THEORY ENGINES
--------------------------------------------------------------------------------

A. SENSOR FUSION & ATTITUDE ESTIMATION (Madgwick Algorithm / `ahrs` Equivalent)
   - Quaternion Differential Kinematics:
     $\dot{\mathbf{q}}_\omega = \frac{1}{2} \mathbf{q} \otimes \mathbf{\omega}$
   - Gradient Descent Gravity Vector Error Minimization ($\beta = 0.45$):
     $\mathbf{q}_k = \mathbf{q}_{k-1} + (\dot{\mathbf{q}}_\omega - \beta \frac{\nabla f}{\|\nabla f\|}) \Delta t$
   - Converts unit quaternion $\mathbf{q}$ to Tait-Bryan Euler Angles (Pitch $\theta$, Roll $\phi$, Yaw $\psi$).

B. ATMOSPHERIC THERMODYNAMICS & SOUNDINGS (`MetPy` Formulation)
   - Magnus-Tetens Dew Point ($T_{\text{dew}}$):
     $\alpha(T, RH) = \frac{17.625 \cdot T}{243.04 + T} + \ln\left(\frac{RH}{100}\right), \quad T_{\text{dew}} = \frac{243.04 \cdot \alpha}{17.625 - \alpha}$
   - Ideal Gas Law Atmospheric Air Density ($\rho$):
     $\rho = \frac{P \times 100}{287.058 \cdot (T + 273.15)} \quad (\text{kg/m}^3)$
   - Tropospheric Environmental Lapse Rate (ELR):
     $\Gamma = -\left(\frac{T_t - T_{\text{pad}}}{h_t - h_{\text{pad}}}\right) \times 100 \quad (^\circ\text{C} / 100\,\text{m})$

C. STATE ESTIMATION & GEODESY (`FilterPy` Formulation)
   - GPS Coordinate Low-Pass Filter ($\alpha = 0.65$ Exponential Moving Average):
     $\hat{\mathbf{p}}_t = \alpha \mathbf{p}_t + (1 - \alpha) \hat{\mathbf{p}}_{t-1}$
   - Equirectangular Planar Geodesic Distance & Forward Azimuth Bearing.

5. FRONTEND & GRAPHICAL VISUALIZATION LIBRARIES
--------------------------------------------------------------------------------
1. Three.js (v0.128.0): WebGL 3D Scene Graph Engine rendering the PBR CanSat model 
   with solar panel arrays, antenna, Cartesian axis indicators, and quaternion slerp at 60 FPS.
2. Chart.js (v4.4.1): HTML5 Canvas 2D engine managing 7 concurrent real-time line charts 
   using $O(1)$ ring buffer eviction ($N=50$) with zero layout animation latency.
3. Leaflet.js (v1.9.4): GIS mapping engine with ESRI Satellite, CartoDB Dark Matter, 
   and OpenStreetMap base layers with ascent/descent polyline path rendering.
4. Tailwind CSS (v3.x JIT): GPU-composited dark-space luxury glassmorphism design tokens.
5. Web Serial API (`navigator.serial`): Asynchronous USB hardware serial reader at 115200 baud.
6. Web Speech API (`window.speechSynthesis`): Real-time voice telemetry callouts.

7. HOW TO LAUNCH & RUN THE SYSTEM
--------------------------------------------------------------------------------

1. Launch the Python Machine Learning Server:
   - In PowerShell:
     `powershell -ExecutionPolicy Bypass -File E:\Cansat\backend\start_server.ps1`
   - Or in Command Prompt:
     `E:\Cansat\backend\start_server.bat`
   - Or directly via Python:
     `E:\Cansat\.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8000 --reload`

2. Open the Ground Station Dashboard:
   - Double-click `E:\Cansat\index.html` in Google Chrome or Microsoft Edge.
   - The top header will display `PYTHON ML (ONLINE)` in glowing green.
   - Click "DEMO REALTIME", connect a USB Serial radio, or replay any test flight profile.
