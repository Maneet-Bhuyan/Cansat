# Aerial Camera Captures & Telemetry Video Snapshots

This directory stores test frames, snapshots, and image captures received from the ESP32-CAM airborne payload node over 2.4 GHz ESP-NOW.

## Captured Files:
- `last_live_snapshot.jpg`: Raw 320x240 JPEG test frame captured over ESP-NOW at 460800 baud.
- `last_live_snapshot_optimized.jpg`: Optimized JPEG frame demonstrating low-latency wireless transmission.
