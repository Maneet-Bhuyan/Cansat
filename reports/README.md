# Cognitive CanSat Flight Telemetry Reports & Figures

This directory contains automated post-flight kinematics reconstruction, atmospheric sounding profiles, and publication-grade flight reports generated by `ml/flight_analyzer.py`.

## Directory Structure

```
reports/
├── all_missions_summary.csv    # Consolidated flight benchmark matrix across all 10 scenarios
├── pdf/                        # Publication-grade vector PDF flight reports (10 mission profiles)
│   ├── 01_nominal_sounding_flight_Flight_Report.pdf
│   ├── 02_high_altitude_burst_1200m_Flight_Report.pdf
│   ├── 03_severe_wind_shear_drift_Flight_Report.pdf
│   ├── 04_apogee_ejection_shock_tumble_Flight_Report.pdf
│   ├── 05_parachute_pendulum_resonance_Flight_Report.pdf
│   ├── 06_delayed_chute_deployment_Flight_Report.pdf
│   ├── 07_thermal_inversion_sounding_Flight_Report.pdf
│   ├── 08_sensor_glitch_gps_recovery_Flight_Report.pdf
│   ├── 09_low_battery_voltage_sag_Flight_Report.pdf
│   └── 10_ground_pad_static_test_Flight_Report.pdf
└── figures/                    # High-resolution 300 DPI PNG figures for papers and presentations
    ├── *_Altitude_vs_Time.png
    ├── *_Velocity_Profile.png
    ├── *_G_Shock_Profile.png
    ├── *_Atmospheric_Sounding.png
    ├── *_Publication_4Panel.png
    └── *_Summary_Table.png
```

## Regeneration

To regenerate all reports and figures from raw CSV telemetry in `test_cases/`:

```powershell
.\.venv\Scripts\python.exe ml/flight_analyzer.py --all
```
