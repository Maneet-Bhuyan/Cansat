MISSION CONTEXT & FUNDAMENTALS

What is a CanSat & Why This Project Exists

A CanSat is a simulation of a real artificial satellite, integrated within the strict volume and shape of a standard soft-drink can (66mm diameter, 115mm height). Launched via model rockets or drones, they test core space systems, atmospheric data collection, and recovery procedures.

The Core Vulnerability

The Core Engineering Challenge

Traditional CanSats act like falling stones under a parachute—drifting completely blind into water bodies, power lines, or urban structures, resulting in total vehicle loss.

Our Innovation

The Cognitive CanSat Solution

Equipping the probe with an independent vision processor allows it to analyze terrain directly beneath it and steer away from danger autonomously before touchdown.

REAL-WORLD IMPACT

Beyond the Soda Can: Where This Technology Matters

Autonomous edge perception developed for pico-satellites directly scales to mission-critical aerospace, planetary science, and terrestrial disaster robotics where communication latency prevents remote human control.

Disaster Response

Emergency Disaster Mapping

Rapid drop-deployment of micro-probes into active disaster zones (wildfires, structural collapses, chemical spills) to map safe landing paths and locate survivors without risking human lives.

Deep Space Missions

Planetary Exploration Probes

Autonomous landing hazard avoidance for atmospheric entry vehicles on Mars, Titan, or Venus, where round-trip communication delays make real-time remote piloting impossible.

Ecological Sounding

Precision Environmental Dropsondes

Targeted sensor deployment into dense forest canopies, arctic tundras, or rugged mountain ranges for localized ecological data gathering.

THE PROBLEM STATEMENT

The Blind Landing Hazard & Telemetry Bottleneck

Breaks down why conventional atmospheric descent systems fail under competition and real-world conditions.

Card 01 // Form Factor

A Satellite in a Soda Can

Strict physical constraints (66mm × 115mm volume, max 350g mass) mandated by aerospace competitions worldwide mimic real satellite payload limits.

Card 02 // The Hazard

Blind Ballistic Drift

Without guidance, over 40% of standard parachute drops land in hazardous zones or get destroyed upon impact because passive parachutes cannot compensate for crosswinds or obstacles.

Card 03 // RF Bottleneck

The RF Bandwidth Choke

Transmitting raw video over amateur radio frequencies (LoRa/RF) is physically impossible. A single 480p frame (~15 KB) creates massive packet congestion, introducing 1.8 to 2.5 seconds of network latency.

Reflex Edge Architecture

Onboard Reflex Intelligence: Think in the Air, Don't Stream

By deploying an INT8 quantized convolutional neural network (TinyLandingNet) directly into the ESP32-CAM's internal 520 KB SRAM, the CanSat processes frames in 38 milliseconds. It classifies ground hazards and commands autonomous parafoil steering without depending on ground radio links.

SOFTWARE & EDGE ARCHITECTURE

Onboard Software & Perception Architecture

A real-time, deterministic embedded pipeline executing on the ESP32-CAM. FreeRTOS partitions optical capture and neural inference onto Core 0, while Core 1 calculates spatial hazard gradients, evaluates the flight state machine, and dispatches steering commands.

Core 0 // Perception

DMA Frame Ingestion

Direct Memory Access (DMA) pulls raw grayscale frames from the OV3660 camera sensor via the DVP parallel bus. Frames are downsampled in-place into a normalized 64×48 tensor directly inside internal SRAM, avoiding external PSRAM bus latency.

Rate: 10 FPS · Buffer: 3.07 KB
Core 0 // Inference

INT8 Quantized Forward Pass

Executes TinyLandingNet via ESP-NN hardware-accelerated vector assembly. Operates on 8-bit quantized weights and activations to classify the terrain beneath the probe into a 3×3 spatial hazard grid in exactly 38 milliseconds.

Latency: 38 ms · SRAM: 142 KB
Core 1 // Guidance

Hazard Gradient & Evasion

Calculates the Surface Landing Area Index (SLAI) across all 9 sectors. If the center nadir sector [1,1] exceeds the 0.65 hazard threshold, a 2D spatial gradient vector determines the lowest-risk trajectory to command autonomous parafoil steering.

Resolution: 3×3 Grid · Threshold: 0.65
Core 1 // Downlink

Dual-Stream Telemetry

Downlinks real-time 13-field physical telemetry plus an embedded hazard bitmask over the 433MHz LoRa link (9600 baud). Concurrently triggers hardware PWM duty cycle shifts to actuate the left or right parafoil control line.

Baud: 9600 · Protocol: Custom CSV
Deterministic Execution

Zero-Copy SRAM Pipeline: 100 ms Control Loop Budget

By eliminating OS context switches and dynamic memory allocation (malloc) during descent, the entire perceive-plan-act cycle executes well within the 100 ms control loop budget. The CanSat re-evaluates ground safety every 50 cm of vertical descent.
