2. RISHI — DATA ANALYTICS, TELEMETRY ANALYSIS & FLIGHT DYNAMICS
================================================================================
Primary Responsibilities: Validating kinematics formulas, analyzing recorded flight
profiles, sensor accuracy auditing, and statistical post-flight analysis.

[ ] TASK DA-01: FLIGHT KINEMATICS & TRAJECTORY ANALYSIS
    - Analyze real-time and recorded 17-column CSV telemetry logs.
    - Validate vertical descent speed: v_spd = (alt[t] - alt[t-1]) / delta_t.
    - Verify resultant G-force calculations: |G| = sqrt(ax^2 + ay^2 + az^2).
    - Check for g-shock peaks during launch, apogee ejection, and parachute deployment.
    - Reference files: test_cases/*.csv, tests/selftest.js

[ ] TASK DA-02: ATMOSPHERIC SOUNDING & METEOROLOGICAL METRICS
    - Validate barometric pressure decay profiles against standard atmosphere model (ISA).
    - Compute Environmental Lapse Rate (ELR in °C / 100m) from temperature-altitude slopes.
    - Verify Magnus-Tetens Dew Point calculation: T_dew = (b * alpha) / (a - alpha).
    - Verify Ideal Gas Law dry air density calculation: rho = P / (R_spec * T_kelvin).

[ ] TASK DA-03: SENSOR FUSION DRIFT & ATTITUDE ACCURACY AUDIT
    - Benchmark raw gyroscope angular rates (gx, gy, gz) against fused pitch/roll angles.
    - Audit drift behavior over 10-minute static pad test (test_cases/10_ground_pad_static_test.csv).
    - Validate Madgwick quaternion filter attitude accuracy during dynamic rotational wobble.

[ ] TASK DA-04: ANOMALY DETECTION THRESHOLD CALIBRATION
    - Calibrate empirical anomaly detection trigger boundaries:
      * Excessive Gyro Tumble (> 150°/s)
      * Severe Shock Impact (> 4.5 G)
      * Low Battery Voltage Sag (< 3.50 V)
      * Freefall Drop Glitch (|G| < 0.15 G for > 2 seconds)
    - Review false-positive rates on historical sounding test runs.

[ ] TASK DA-05: AUTOMATED POST-FLIGHT ANALYSIS REPORT SCRIPT
    - Develop Python notebook / script (using pandas, matplotlib, scipy) in ml/ or backend/:
      * Automated CSV ingestion
      * Time-series plots: Altitude vs Time, Velocity Profile, G-Forces, Pressure-Temperature Profile
      * Flight summary statistics table (Apogee altitude, Max ascent velocity, Touchdown shock, Mission duration)
      * Export publication-ready PDF/PNG figures for Ganesh's paper.
