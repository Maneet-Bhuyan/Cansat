5. GENERAL REPOSITORY ACCESS INSTRUCTIONS (Share in the group)
--------------------------------------------------------------------------------
🛠️ *Cognitive CanSat - Repository & Quick Setup Guide*

1. *Prerequisites*:
   - Git, Python 3.10+, Node.js (for test runner), Arduino IDE / Arduino CLI.
2. *Setup*:
   ```powershell
   cd E:\Cansat
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r backend/requirements.txt  # or pyserial opencv-python fastapi uvicorn
   ```
3. *Run Automated Verification*:
   ```powershell
   node tests/selftest.js
   ```
4. *Launch Ground Station*:
   ```powershell
   .venv\Scripts\python.exe launch.py
   # Opens Mission Control dashboard at http://127.0.0.1:8000
   ```
5. *View Camera Stream Standalone*:
   ```powershell
   .venv\Scripts\python.exe firmware/ground_cam_viewer.py --port COM5
   ```
